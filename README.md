# Netflix Clone

A Netflix-inspired website built using HTML and CSS. This project recreates the look and feel of the Netflix landing page with a modern and responsive design.

## Features

* Responsive design
* Netflix-style homepage
* Modern user interface
* Attractive layouts and sections
* HTML5 and CSS3 implementation

## Technologies Used

* HTML5
* CSS3

## Project Structure

* `index.html` - Main webpage
* `style.css` - Styling and layout

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.
3. Explore the Netflix-inspired interface.

## Learning Outcomes

This project helped in learning:

* HTML page structure
* CSS styling and layouts
* Responsive web design
* Building real-world website clones
